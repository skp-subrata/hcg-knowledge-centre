Auto-detection Engine

No need to categorize uploads. Type of links (YouTube/PDF/PPT) and uploaded files are auto-detected instantly.

A full 4-step wizard modal to create courses with save-as-draft support, preview review, and dynamic flow.

Impersonation ("View As")

Admins can switch views and temporarily preview the LMS exactly as any basic user sees it.

Advanced Management Search

Perform real-time queries with filter chips and sectional fields for Courses, Users, and Assessments.

Added secure embed layout for Microsoft Office Viewer and local fallback alerts.

  • Fixed top navigation bar overlay z-index alignment during course creation.
  • Resolved duplicate endpoint crash and role-switching errors.
